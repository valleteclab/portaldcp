1
Visão Geral do Fluxo
Entenda o processo completo antes de começar

Uma requisição de contrato de compras é um pedido formal para o fornecimento de materiais previstos em um contrato ativo. O fluxo é composto por 4 etapas e possui as seguintes transições de status:

Rascunho
→
Aguardando Autorização
→
Autorizada
→
Ordem Gerada
→
Atendida
Tipo abordado neste manual Tipo: MATERIAL · Categoria do Contrato: COMPRAS · Etapas: 4 (Contrato → Itens → Dados → Resumo)
Importante — Reserva de Saldo Ao criar a requisição, o saldo dos itens selecionados é reservado imediatamente no contrato. Certifique-se de que as quantidades são corretas antes de salvar.

3
Iniciando uma Nova Requisição
Clique em "+ Nova Requisição" para abrir o formulário

Ao clicar em + Nova Requisição, você será redirecionado para a página https://compras.cmlem.ba.gov.br/orgao/almoxarifado/requisicoes/nova. O sistema inicia na Etapa 1 — Contrato.

Auto-save automático O sistema salva automaticamente um rascunho no navegador a cada 2 segundos de inatividade. Se você fechar a aba por acidente, ao retornar será perguntado se deseja recuperar o rascunho.
4
Etapa 1 — Selecionar Contrato
Escolha o contrato de compras de onde serão solicitados os materiais
  • Filtre por categoria clicando em Compras para ver apenas contratos do tipo correto
  • Use a busca para localizar o contrato pelo número, objeto ou fornecedor
  • Clique no card do contrato desejado (ficará com borda azul e fundo azul claro)
  • Verifique o saldo disponível e os dias restantes de vigência
  • Clique em Próximo → para avançar

5
Etapa 2 — Selecionar Itens
Escolha os itens do contrato e defina as quantidades
  • O sistema exibe automaticamente os itens do contrato selecionado, com saldo disponível de cada um
  • Clique no item ou na caixa de seleção para adicioná-lo à requisição
  • Ajuste a quantidade usando os botões − e + ou digitando diretamente no campo
  • Utilize "Pedir tudo" para solicitar o saldo máximo de todos os itens com saldo disponível
  • Use a busca para filtrar itens por descrição
  • Clique em Próximo → para avançar

6
Etapa 3 — Dados da Requisição
Preencha as informações do pedido: setor, justificativa, prioridade e prazo
  • Selecione o Setor Solicitante no menu suspenso (se houver setores cadastrados) ou preencha manualmente
  • Informe o Local de Entrega — endereço ou sala onde o material deve ser entregue
  • Preencha a Justificativa descrevendo a necessidade — use os modelos prontos para agilizar
  • Defina a Prioridade: Baixa, Normal, Alta ou Urgente
  • Informe a Data de Necessidade (opcional) — prazo esperado para recebimento
  • Adicione Observações adicionais se necessário (campo opcional)
  • Clique em Próximo → para ver o resumo

7
Etapa 4 — Resumo e Envio
Revise todos os dados antes de salvar ou enviar para autorização
  • Confira todos os dados: contrato, fornecedor, itens, quantidades e valores
  • Verifique o valor total da requisição destacado em verde
  • Leia o alerta sobre reserva de saldo — ao salvar, o saldo é imediatamente reservado
  • Escolha uma das ações: Salvar como Rascunho ou Enviar para Autorização

8
Após o Envio — Ciclo de Status
O que acontece depois que a requisição é enviada para autorização

Após enviada, a requisição fica visível na lista com o status Aguardando Autorização. O gestor pode autorizar, negar ou cancelar a requisição.
