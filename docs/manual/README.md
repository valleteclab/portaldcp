# Manual do Usuário — Módulo de Licitações do Portal DCP

> Versão de 25/09/2026 · Base legal: Lei 14.133/2021, LC 123/2006, IN SEGES 67/2021 e 73/2022
> Público: servidores municipais (agentes de contratação, pregoeiros, equipes de apoio, autoridades, administradores do órgão), fornecedores e cidadãos.

Este manual explica, em linguagem simples, como usar o módulo de licitações do Portal DCP do começo ao fim: da demanda ao contrato (ou à ata de registro de preços) e à publicação no PNCP.

Ele descreve o sistema **como ele está hoje**. Quando uma função ainda não existe, o manual diz isso claramente ("não disponível" ou "em breve").

## Como ler este manual

- Se você é **servidor do órgão**, comece pela [Visão geral](00-visao-geral.md) e depois leia a parte da sua tarefa.
- Se você é **fornecedor**, vá direto para o [Guia do fornecedor](12-fornecedor.md).
- Se você é **cidadão** e quer acompanhar uma licitação, leia [Cidadão e transparência](13-cidadao-e-transparencia.md).
- Teve um problema? Veja as [Perguntas frequentes](14-perguntas-frequentes.md).

Nos textos:

- **Negrito** indica o nome de um botão, menu, aba ou cartão, do jeito que aparece na tela.
- `Menu › Submenu` indica o caminho a seguir.
- Os quadros **Atenção** mostram regras que o sistema aplica sozinho, com o artigo da lei correspondente.
- Todos os horários são de **Brasília** (UTC-3).
